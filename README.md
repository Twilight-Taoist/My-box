# My-box

我的 C 语言练习仓库 · 2026 级 · 数据科学与大数据技术

## 这是什么

从 2026 年 7 月开始自学 C 语言以来写的练习代码，按学习顺序存放。
每个练习都在这台电脑上编译、运行、确认输出正确之后才提交。

- **编译器**：Dev-C++ 5.11 自带的 TDM-GCC 4.9.2（64 位）
- **编译参数**：`-std=c11 -Wall -Wextra`
- **编码说明**：仓库里的 `.c` 是 UTF-8，所以在 GitHub 网页上中文注释能正常显示。
  如果下载到本机用 Dev-C++ 打开，需要把编辑器编码切成 UTF-8 才能看到中文注释
  （Dev-C++ 默认按 GBK 打开）。

## 关于「链表的尝试」

同一个链表练习写了三遍，一遍比一遍独立：

- **`链表的尝试01.c`** —— 第一遍：节点定义、头插、遍历
- **`链表的尝试02.c`** —— 第二遍：头插和尾插各写两版（返回新表头 ∥ 二级指针）、按位置插入、查找、修改、删除所有值为 v 的节点
- **`链表的尝试03.c`** —— 第三遍：**不看参考，徒手重写增删改查**

为什么要写三遍：一开始的问题是「读得懂别人的代码，但自己写不出来」。
改了学习方法之后——抽查从口头问答改成必须动手写代码——第三遍才写顺。
`链表的尝试02.c` 和 `链表的尝试03.c` 的差别，就是这个过程留下的记录。

## 怎么编译

用 Dev-C++ 直接打开 `.c` 文件按 F11 即可。命令行下：

```bat
gcc -std=c11 -Wall -Wextra 链表的尝试02.c -o test.exe
test.exe
```
