# csharp/ —— C# 阶段的练习仓库目录

> **为什么放在仓库里**（而不是 VS 默认的 `C:\Users\dxszhj\source\repos\`）：
> 这样 **Visual Studio 2026 自带的 Git 面板可以直接提交/推送**，而且能看到"哪些文件改了" ——
> 不用再靠外部脚本搬文件。C 语言阶段的 `code/` 仍由 `一键推送到GitHub.ps1` 负责。

## 放什么

- **正式的 C# 练习项目**：每个知识点/每章一个项目，例如
  - `Day01_Basics/`（第 01 章：语法与变量类型）
  - `Day02_.../`
- **不要把** `bin/`、`obj/`、`.vs/` 提交上来（`.gitignore` 已排除）

## 怎么提交（VS 2026）

1. VS 里 **打开项目**：`...\编程\git\csharp\Day01_Basics\Day01_Basics.csproj`
   （或 **文件 → 打开 → 文件夹** → 选 `...\编程\git`）
2. 改完代码 → 右侧 **「Git 更改」**面板 → 填**提交信息** → **「提交并推送」**
3. **提交信息写得有意义**（这是你以后面试可展示的部分），例如：
   - `C# 第01章：变量/类型/转换练习（Day01_Basics）`
   - `C# 第02章：控制流练习`

## 判据（每次推完看两眼）

- VS 的 Git 面板显示 **"已同步"/"nothing to push"**
- 或命令行：`git -C "C:\Users\dxszhj\Desktop\编程\git" log --oneline -1` 有你的新提交
- **想更严格**：`git ls-remote origin main` 的哈希 == `git rev-parse HEAD`

## 与旧脚本的分工

| 内容 | 通道 | 提交信息 |
|---|---|---|
| C 语言练习（`编程练习结果\*.c`） | `一键推送到GitHub.ps1` → `code/` | "更新 C 语言练习代码（日期）" |
| **C# 练习（本目录）** | **VS 2026 的 Git 面板** | 你自己写（有意义的信息） |

> 两边都推到同一个仓库 `My-box`（不同目录），互不冲突。
