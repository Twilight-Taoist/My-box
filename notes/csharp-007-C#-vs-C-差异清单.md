### 🔧1 第 1 条："又称算法" ← 存疑
- **核实方法**：回看 007 里讲"方法"的那一段（或 008 开头）。
- **提示**：C# 里 `Method` 通常对应 C 的 `Function`（函数）；"算法"是另一个概念（algorithm）。

### 🔧2 第 3 条："跨块使用要加 `public`" ← 要精确
- **问题**："跨块"太模糊。准确的说法是：**访问修饰符管的是"谁能看见"**，最常用的是 **`public`（任何地方可见）/ `private`（只有本类内可见）**。
- **写清楚的版本**：public 可以让方法在任何地方可见。

### 🔧3 第 5 条：`{0}` 占位符 ← 要补 **C# 更常用的插值**
- 你写的 `Console.WriteLine("{0} + {1} = {2}", a, b, sum)` **是对的**（占位符索引）。
- 但 **C# 现在更常用"字符串插值"**（也是本产出物 `b` 项要求的）：
```csharp
Console.WriteLine($"{a} + {b} = {sum}");   // 更短、更直观，推荐
```
- **一句话区别**：`{0}` 靠**位置**对应参数；`$"…"` 直接把**变量名**写进去。

## 四、📌 纸稿里另外三块内容（**不属于本清单，但写得对，记在这里**）

- **变量的定义**（你写的）："实质上是**以变量名地址为起点、以该类型要求的存储空间为长度的一块内存区域**" ✅ 准确。
- **7 种变量**：静态变量 / 实例变量（成员变量、字段）/ 数组元素 / 值参数 / 引用参数 / 输出形参 / 局部变量 ✅ 与 C# 规范一致。
- **值类型 vs 引用类型的过程**：`Student stu;` → 栈上开槽并默认清零；`stu = new Student();` → 堆上分配、把**起点地址**填回栈；`stu.ID = 1000;` → 写入堆；`stu2 = stu;` → **栈上再开一个槽，把同一个地址拷进去** ✅ 全过程正确。
  → 唯一要补的一句结论：**`stu2 = stu` 之后，两个变量指向同一个对象**（改 `stu2.ID` 会同时影响 `stu`）—— **这正是抽查第 1 题要问的**。
- **装箱 / 拆箱**（纸稿第 3 页）：`object obj; obj = x;` → **堆上复制一个 x、obj 指向它（装箱）**；`int y = obj;` → **按 obj 找到地址、复制回栈（拆箱）** ✅ 正确。
