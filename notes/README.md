# 笔记

这里放**「没有代码可提交」那天的产出**。

比如精讲章（`deep/d12` 存储类别与内存管理、`d13` 文件 I/O、`d15` 位操作）读完之后的整理，
或者某道错题的**验证思路**（为什么错、正确认知是什么、跑出来什么样）。

## 为什么要单独一个目录

不是每天都有代码可写。读一章、做一套自测，那天可能一个 `.c` 都没产出——
但**学过的东西如果不写下来，一周后就等于没学**。

所以约定是：**有代码交代码，没代码交笔记**。

## 命名建议

```
notes/
├─ README.md                    ← 本文件（不用改）
├─ d12-存储类别与内存管理.md
├─ d13-文件IO.md
└─ 错题-五种存储类别.md
```

## 写法（三行就够，别抄书）

每条知识用三行写：

- **是什么** —— 一句话定义
- **为什么** —— 它解决什么问题 / 不这样会怎样
- **例子** —— 一小段代码，或一个具体场景

## 判断标准

> **三个月后自己回看，能不能看懂？**

看得懂 → 合格；看不懂 → 说明当时就没真懂，回去补。
