# 笔记

这里放**「没有代码可提交」那天的产出**。

比如精讲章（`deep/d12` 存储类别与内存管理、`d13` 文件 I/O、`d15` 位操作）读完之后的整理，
或者某道错题的**验证思路**（为什么错、正确认知是什么、跑出来什么样）。

## 为什么要单独一个目录

不是每天都有代码可写。读一章、做一套自测，那天可能一个 `.c` 都没产出——
但**学过的东西如果不写下来，一周后就等于没学**。

所以约定是：**有代码交代码，没代码交笔记**。

## 命名建议

```
notes/
├─ README.md                    ← 本文件（不用改）
├─ d12-存储类别与内存管理.md          ← C 语言阶段（精讲编号 dNN）
├─ d13-文件IO.md
├─ 错题-五种存储类别.md
└─ csharp-007-变量对象与内存.md       ← C# 阶段（2026-10-08 起）：csharp-<集号>-<主题>.md
```

**C# 阶段补充（2026-10-15）**：
- 笔记命名用 **`csharp-<集号>-<主题>.md`**（例：`csharp-007-变量对象与内存.md`），**集号对齐刘铁猛课程的编号**。
- **允许放原始稿**：跟敲时的 `.xlsx` / 截图等可以一起放进来（原始数据也是产出）；
  但**主笔记一律用 `.md`** —— 因为 `.xlsx` 是二进制，git 看不出改了什么，md 才能 diff 与展示。
- 对应规则：**知识类内容 → 笔记 + 抽查**（动手类才要求可运行代码），见 `（.md）\现行判断与策略清单.md` 的 **C10**。

## 纸笔稿（2026-10-15 加入）

**习惯用纸笔写没问题** —— 但要按"**过程 vs 产出物**"分开：

| | 放哪 | 要求 |
|---|---|---|
| **纸稿（拍照/截图）** | `notes/纸笔稿/` | **压缩到宽 1600px**（原图 4 MB → ≈300 KB）后入库；命名 `NNN-主题-YYYY-MM-DD-序号.jpg` |
| **结论（文字）** | `notes/csharp-NNN-主题.md` | **必须写**（是什么/为什么/例子）——**抽查只抽文字**，纸稿是留痕用 |

- **原图**留在本地并纳入离线备份（不要在仓库里堆原图：图片是二进制，历史只增不减）。
- **为什么**：照片不可检索、不可 diff，也无法用来抽查；它证明"你确实在写"，但**不能替代把话说明白**。

## 写法（三行就够，别抄书）

每条知识用三行写：

- **是什么** —— 一句话定义
- **为什么** —— 它解决什么问题 / 不这样会怎样
- **例子** —— 一小段代码，或一个具体场景

## 判断标准

> **三个月后自己回看，能不能看懂？**

看得懂 → 合格；看不懂 → 说明当时就没真懂，回去补。
